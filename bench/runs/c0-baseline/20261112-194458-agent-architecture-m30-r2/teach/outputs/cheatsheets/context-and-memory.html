Context and memory in an agent

From lesson 1. Source: Effective context engineering for AI agents.

Vocabulary

TermMeaning
ContextAll tokens the model is given in one call: system prompt, tool list, messages, tool results.
Context windowThe limit on tokens per call, input and output together.
Context rotRecall gets worse as the context fills; more is not better.
CompactionSummarize a near-full conversation and continue from the summary.
Clearing tool resultsDrop old tool output from later calls.
MemoryA store outside the context, written and read by the program, loaded back into context to matter.
Structured note-takingThe agent saves notes outside the context and reads them later.
RetrievalSearch a large store and load only the best few chunks.
Pre-inference retrievalSearch runs before the model call; the program inserts the result.
Just-in-time retrievalThe model calls a search tool when it needs data.

Rules to remember

  • The model keeps nothing between calls; the program re-sends everything each time.
  • Input cost of a request = sum of the input size of every model call. Each call contains all earlier steps.
  • Nothing carries between sessions unless the program saves it and loads it into the new context.
  • The model only sees what retrieval returns; test the search separately.

Cost arithmetic

Call n input = setup + all earlier tool requests and results. Example: setup 2,050, each step adds 1,050 → 2,050 + 3,100 + 4,150 + 5,200 = 14,500 input tokens.
