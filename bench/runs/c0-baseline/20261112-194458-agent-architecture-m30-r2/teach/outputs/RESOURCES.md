# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, structured note-taking, pre-inference vs just-in-time retrieval, sub-agents. Use for: anything about what an agent keeps in context and how it remembers.
- [Docs: Context windows (Claude docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how turns accumulate, compaction and context editing. Use for: token arithmetic and limits.
- [Docs: Memory tool (Claude docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  File-based memory across sessions, including a multisession pattern. Use for: designing what the assistant saves between visits. Listed from the context-windows page; not read in full yet.
- [Article: "Effective harnesses for long-running agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)
  Handing work between sessions. Use for: later reading on long-running agents. Not read yet.
