# Open misconceptions: the model runs tools itself (M4) and remembers across sessions (M3)

In quiz 0001 (s1) the learner understood the agent loop, step limits and choosing tools from descriptions. They still believed the model opens systems and runs the three tools itself within one call (M4). They also believed the model remembers earlier tool choices across sessions (M3).
Later lessons should separate "model writes a tool request" from "program runs the tool", and should show that memory has to be built by the program.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6 (right on q1, q3 and half of q5 and q6).
