Rules of thumb

  • The model keeps nothing between calls; the program re-sends the context.
  • Input tokens on call N = everything before it. Big tool results are paid for on every later call.
  • More context is not better: recall can fall as it grows (context rot).
  • Save what stays true; fetch what goes stale with a tool.
  • Retrieval: keyword (BM25) for exact codes, embeddings for meaning, both if possible.
  • Memory only helps once it is loaded into the context.

Token arithmetic

Input of call k = input of call k-1 + the model's tool request + the tool result. Total cost of a run = sum of all calls' inputs.
