Context and memory in an agent

From lesson 1.

Terms

TermMeaning
ContextAll tokens the model sees on one call: system prompt, tool descriptions, conversation, tool results.
Context windowThe most tokens the model can take in on one call.
Context rotRecall gets worse as the context grows.
SessionOne conversation; its context is gone when it ends.
Memory (notes)Information saved outside the context and loaded back later.
RetrievalSearching existing material (manuals) and adding only the best chunks.

Rules

  • The model keeps nothing between calls; the program re-sends earlier steps.
  • Cost of a request = sum of the input of every call, not the final context size.
  • Trim: clear old tool results; compact into a summary.
  • Where information lives: about a student, learned earlier → notes. Changes often → tool call. In the manuals → retrieval. Needed for this chat → context.
  • Search by meaning (embeddings) plus exact terms (BM25).
  • If all manuals fit in about 200,000 tokens, you may not need retrieval.
