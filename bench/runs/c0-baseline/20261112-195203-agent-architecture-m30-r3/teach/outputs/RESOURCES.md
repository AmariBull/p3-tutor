# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context window, context rot, just-in-time retrieval, compaction, note-taking, sub-agents. Use for: anything about what goes in the context and how to keep it small.
- [Docs: Memory tool (Claude documentation)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  How a model-requested, app-run file memory works, with security cautions. Use for: designing saved notes between sessions.
- [Article: "Contextual Retrieval" (Anthropic Research)](https://anthropic.com/research/contextual-retrieval)
  Chunks, embeddings, BM25, reranking, and the ~200,000-token rule of thumb for skipping retrieval. Use for: searching long manuals.
